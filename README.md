# Bhagyashree Makhija — Portfolio

Personal portfolio website for **Bhagyashree Makhija**, Software Engineer based in Pune, India.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Publish

The site can be deployed through GitHub Pages or Vercel/Netlify. For GitHub Pages, enable **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then save.
